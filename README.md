# 우동 — 오늘 우리 동네 한눈에

공공기관 동네 공지와 공공시설 빈자리를 한눈에 보여주는 웹 서비스, **우동**의 첫 버전입니다.

## 이 버전에서 할 수 있는 것

- 동네를 고르고 오늘 날짜를 확인합니다.
- 오늘 꼭 봐야 할 긴급 공지(단수, 도로 통제)를 먼저 봅니다.
- 오늘 공지를 분류 칩으로 골라 봅니다. 전체 / 공사·교통 / 행사 / 복지 / 생활
- 지금 빈자리를 봅니다. 도서관 열람실, 체육관 배드민턴장, 공영주차장
- 모바일에서 한 손으로 보기 좋은 한 화면 구성입니다.

## 파일

- `index.html` — 우동 웹 첫 버전. 서버 없이 브라우저로 바로 열 수 있습니다. `data.json`이 있으면 자동으로 가져온 공지를 먼저 보여줍니다.
- `data.json` — 자동 수집 결과. `scripts/fetch.py`가 만듭니다.
- `scripts/fetch.py` — 자동 수집 스크립트. 서울 열린데이터광장 API를 쓰고, API 키가 없으면 가짜 데이터를 만들지 않고 상태를 기록합니다.
- `sources.yaml` — 출처 목록. RSS/XML 주소가 확인된 출처만 추가합니다.
- `.github/workflows/update.yml` — 매일 07:00, 18:00 KST에 자동 수집하고 바뀐 `data.json`만 커밋합니다.

## 자동 수집 v0.4 — 전국 8개 지역

```bash
python3 scripts/fetch.py
# -> data.json (성동구 13개), data_nationwide.json (강남·서초·노원·구로·금천·대구·군위, 각 10개씩 총 70개)
```

RSS가 직접 가져오기로 확인된 지역만 넣었다. 구미시는 RSS 주소로 열면 HTML 포털이 나와서 제외했다. 성동구는 이 서버에서 직접 가져오면 연결이 끊겨, 실패하면 기존 소식을 유지하고 정기 작업에서 브라우저로 확인한다. RSS가 없는 지역은 `sources_nationwide.yaml`에 목록 URL을 모아두고, 목록 HTML 읽기 / 정부24 지자체 소식 집계로 연결하는 게 다음 단계이다.

```bash
SEOUL_API_KEY=... python3 scripts/fetch.py
```

서울 열린데이터광장 인증키는 https://data.seoul.go.kr/ 에서 발급받습니다. GitHub에서는 저장소 Settings → Secrets → `SEOUL_API_KEY`로 넣습니다. 키를 코드나 채팅에 넣지 않습니다.

성동구청 새소식 RSS를 2026-11-18에 확인했다. `https://www.sd.go.kr/rssBbsNtt.do?bbsNo=183&integrDeptCode=` (최신 10개). `data.json`에는 2026-11-18 기준 실제 공지 13개가 들어 있다. 단, 이 서버에서 직접 가져오면 연결이 끊기는 경우가 있어, `scripts/fetch.py`는 가져오기가 실패하면 기존 소식을 유지하고 실패를 기록한다. 정기 작업에서는 브라우저로 RSS를 확인하는 방식을 같이 쓴다.

복지 공지는 새소식 안에 별도 분류가 없고 제목 검색으로 찾는다. 부모급여·복지로 안내는 분야별정보 > 복지 안내 페이지에 있다.

## 샘플 데이터 안내

이 버전의 공지와 빈자리 내용은 실제 공공기관 데이터가 아니라 화면 구조를 확인하기 위한 예시입니다. 실제 데이터 연동은 다음 단계에서 출처를 달고 붙일 예정입니다.

## 로컬에서 보기

```bash
python3 -m http.server --directory .
```

브라우저에서 `http://localhost:8000/` 을 엽니다. `index.html` 파일을 직접 더블클릭해서 열어도 됩니다.
