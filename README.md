# 우동 — 오늘 우리 동네 한눈에

공공기관 동네 공지와 공공시설 빈자리를 한눈에 보여주는 웹 서비스, **우동**의 첫 버전입니다.

## 이 버전에서 할 수 있는 것

- 동네를 고르고 오늘 날짜를 확인합니다.
- 오늘 꼭 봐야 할 긴급 공지(단수, 도로 통제)를 먼저 봅니다.
- 오늘 공지를 분류 칩으로 골라 봅니다. 전체 / 공사·교통 / 행사 / 복지 / 생활
- 지금 빈자리를 봅니다. 도서관 열람실, 체육관 배드민턴장, 공영주차장
- 모바일에서 한 손으로 보기 좋은 한 화면 구성입니다.

## 파일

- `index.html` — 우동 웹 첫 버전(v0.1). 서버 없이 브라우저로 바로 열 수 있습니다.

## 샘플 데이터 안내

이 버전의 공지와 빈자리 내용은 실제 공공기관 데이터가 아니라 화면 구조를 확인하기 위한 예시입니다. 실제 데이터 연동은 다음 단계에서 출처를 달고 붙일 예정입니다.

## 로컬에서 보기

```bash
python3 -m http.server --directory .
```

브라우저에서 `http://localhost:8000/` 을 엽니다. `index.html` 파일을 직접 더블클릭해서 열어도 됩니다.

## 다음 단계

1. 실제 동네를 정하고, 해당 구청·주민센터 공지 출처를 정합니다.
2. 공공시설 빈자리의 실제 출처와 갱신 주기를 정합니다.
3. GitHub Pages로 공개 링크를 만듭니다.
